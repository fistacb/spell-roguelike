# spell-roguelike

言葉と旅するローグライト（試作）。

自由入力の呪文で場面のオブジェクトに干渉し、その結果が次の場面（戦闘）に引き継がれるかを試すための試作です。

## 遊び方

1. 場面A「崖下の小道」：女の子の頭上に岩が落ちてくる。呪文は1回だけ。
2. 場面B「いたずら小鬼」：場面Aの結果で条件が変わる短い戦闘。
3. 旅の記録：見つけた言葉、使った魔法、新しい発見を振り返る。

呪文の例：「岩に雷槍」「小川に氷」「土壁」「女の子に強化」「枯れ木に炎」

## 開発

```sh
npm install
npm run dev    # 開発サーバー（スマホからも開けるよう --host 付き）
npm test       # ルールの自動テスト
npm run build  # dist/index.html に1ファイルで出力（アーティファクト用）
```

## 構成

- `src/game/` ルール（画面に依存しない）
  - `words.ts` 辞書と初期所持ワード
  - `parse.ts` 呪文の解析（最長一致、ひらがなは読み飛ばす、文字数は全文字）
  - `sceneA.ts` 場面Aの反応
  - `battle.ts` 場面Bの戦闘
  - `run.ts` 1回の旅の進行
  - `save.ts` localStorage への保存
- `src/main.ts` 画面
- `tests/` ルールのテスト
