# spell-roguelike

言葉と旅するローグライト（試作）。

自由入力の呪文で場面のオブジェクトに干渉し、その結果が次の場面（戦闘）に引き継がれるかを試すための試作です。

## 遊び方

- 1回の旅は3ステージ×5場面。最初は「故郷の村はずれ」で、「女の子と落石」→「いたずら小鬼」の1組が必ず出る。
- ステージの終わりに宿（ハート回復・途中の記録）と分かれ道がある。分かれ道では、ふさいでいる物（大岩・大川・霧）に効く言葉を唱えると山道・川沿いの道・霧の森へ進める。何も開かなければ街道。
- 詠唱できる文字数はステージごとに2増える（6→8→10）。
- 言葉は旅の中で増える：場面のお礼（癒し・鎖など）、地域の言葉（響き・流れ・眠り・引き寄せ）、出来事の言葉（煙・霜・礫・灰・静けさ）、2つを混ぜて生まれる言葉（蒸気・泥・嵐・火の粉）。持てるのは12個まで。
- 言葉の効果ははっきり説明しない。カードをタップすると、ふわっとした一言だけが出る。
- どの場面も詠唱は1回だけ。戦闘も、予告を見て「倒す」と「守る」を1つの呪文に詰める。
- 体力はハート（最大5、始めは3）。0になると「君は疲れたので故郷に帰ることにした。」
- 呪文の例：「岩に雷槍」「小川に氷」「炎槍土壁」「あいつに炎雨」「井戸に強化」

## 開発

```sh
npm install
npm run dev    # 開発サーバー（スマホからも開けるよう --host 付き）
npm test       # ルールの自動テスト
npm run build  # dist/index.html に1ファイルで出力
npm run build:artifact  # 試遊用アーティファクトの本文 dist/artifact.html も出力
```

## 構成

- `src/game/` ルール（画面に依存しない）
  - `words.ts` 辞書と初期所持ワード
  - `parse.ts` 呪文の解析（最長一致、ひらがなは読み飛ばす、文字数は全文字）
  - `scene.ts` 場面の共通の型と、1回の詠唱で決着する戦闘の計算
  - `scenes/` 場面ごとの反応（全17場面）、分かれ道、地域とステージの組み立て
  - `run.ts` 1回の旅の進行（ハート、文字数の上限、禁忌）
  - `save.ts` localStorage への保存
- `src/main.ts` 画面
- `tests/` ルールのテスト
