# spell-roguelike

言葉と旅するローグライト（試作）。

自由入力の呪文で場面のオブジェクトに干渉し、その結果が次の場面（戦闘）に引き継がれるかを試すための試作です。

## 遊び方

- 1回の旅は5場面。「女の子と落石」→「いたずら小鬼」の1組と、「吊り橋の狼」「燃える納屋」「道をふさぐ熊」「沼のスライム」から3つがランダムな順で出る。
- どの場面も詠唱は1回だけ。戦闘も、予告を見て「倒す」と「守る」を1つの呪文に詰める。
- 体力はハート（最大5、始めは3）。0になると「君は疲れたので故郷に帰ることにした。」
- 呪文の例：「岩に雷槍」「小川に氷」「炎槍土壁」「あいつに炎雨」「井戸に強化」

## 開発

```sh
npm install
npm run dev    # 開発サーバー（スマホからも開けるよう --host 付き）
npm test       # ルールの自動テスト
npm run build  # dist/index.html に1ファイルで出力
npm run build:artifact  # 試遊用アーティファクトの本文 dist/artifact.html も出力
```

## 構成

- `src/game/` ルール（画面に依存しない）
  - `words.ts` 辞書と初期所持ワード
  - `parse.ts` 呪文の解析（最長一致、ひらがなは読み飛ばす、文字数は全文字）
  - `scene.ts` 場面の共通の型と、1回の詠唱で決着する戦闘の計算
  - `scenes/` 場面ごとの反応（落石、小鬼、狼、納屋、熊、スライム）と旅の組み立て
  - `run.ts` 1回の旅の進行（ハート、文字数の上限、禁忌）
  - `save.ts` localStorage への保存
- `src/main.ts` 画面
- `tests/` ルールのテスト
